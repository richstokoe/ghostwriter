# Sample project

A demo book bundled with Ghostwriter so the app has something to open on first run.

The text is **_Alice's Adventures in Wonderland_ by Lewis Carroll (1865)**, a work in the
public domain, reproduced here as plain text with no third-party licence, headers, or
footers attached. The per-chapter outlines are short editorial summaries written for the demo.
The character profiles were produced by Ghostwriter's own "Build from chapters" feature,
reading the public-domain text, and are included so the character bible isn't empty on first run.
