# Sample project

A demo book bundled with Ghostwriter so the app has something to open on first run.

The text is **_Alice's Adventures in Wonderland_ by Lewis Carroll (1865)**, a work in the
public domain. This copy was sourced from [Project Gutenberg](https://www.gutenberg.org/ebooks/28885);
the Project Gutenberg header, footer, and licence have been removed, leaving only the
public-domain text. The per-chapter briefs are short editorial summaries written for the demo.
